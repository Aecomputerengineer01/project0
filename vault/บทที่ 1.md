# บทที่ 1 บทนำ (Introduction)

## 1.1 ที่มาและความสำคัญของโครงงาน

ในปัจจุบัน ตลาดอสังหาริมทรัพย์และการลงทุนในทรัพย์สินจากการขายทอดตลาดของกรมบังคับคดีได้รับความสนใจจากนักลงทุนและประชาชนทั่วไปเป็นอย่างมาก เนื่องจากเป็นช่องทางที่ทำให้สามารถเข้าถึงที่อยู่อาศัย อาคาร และที่ดินในราคาที่ต่ำกว่าราคาประเมินหรือราคาตลาดทั่วไป อย่างไรก็ตาม ข้อมูลเกี่ยวกับทรัพย์บังคับคดียังคงมีความซับซ้อน ข้อมูลถูกจัดเก็บอย่างกระจัดกระจาย และขาดเครื่องมือดิจิทัลที่ช่วยในการวิเคราะห์ตัดสินใจเชิงลึก เช่น การคำนวณต้นทุนแฝง ภาระการติดจำนอง ค่าธรรมเนียมการโอนกรรมสิทธิ์ รวมถึงการคำนวณเพดานราคาประมูลที่เหมาะสม (Maximum Bid) ซึ่งปัจจัยเหล่านี้ส่งผลให้ผู้ซื้อหน้าใหม่ นักลงทุนรายย่อย หรือประชาชนทั่วไปเสียเปรียบและมีความเสี่ยงสูงในการลงทุน

ขณะเดียวกัน ในพื้นที่ภาคตะวันออกเฉียงเหนือ โดยเฉพาะ **จังหวัดกาฬสินธุ์** มีอัตลักษณ์ทางสถาปัตยกรรมและภูมิปัญญาท้องถิ่นที่โดดเด่นคือ **"สิ่งปลูกสร้างไม้เก่า"** หรือบ้านเรือนไม้โบราณ ซึ่งในปัจจุบันเจ้าของที่ดินจำนวนมากมีการรื้อถอนเพื่อก่อสร้างที่อยู่อาศัยใหม่ในรูปแบบทันสมัย ทำให้เกิดการประกาศขายบ้านไม้เก่าและวัสดุไม้ประกอบอาคารจำนวนมาก ส่งผลให้ตลาดการค้าไม้เก่าและสิ่งปลูกสร้างไม้เก่ากลายเป็นตลาดเฉพาะกลุ่ม (Niche Market)ที่มีมูลค่าทางเศรษฐกิจสูง อย่างไรก็ดี ในปัจจุบันยังคงขาดแพลตฟอร์มกลางทางดิจิทัลที่เชื่อมโยงระหว่างผู้ขาย เจ้าของบ้านไม้ ผู้รับเหมารื้อถอน และผู้ซื้อที่ต้องการนำไม้ไปใช้งานใหม่หรือรีไซเคิลอย่างครบวงจร

ด้วยเหตุนี้ ผู้จัดทำจึงมีแนวคิดในการออกแบบและพัฒนา **"เว็บไซต์และแอปพลิเคชันตลาดอสังหาริมทรัพย์ ทรัพย์บังคับคดี และสิ่งปลูกสร้างไม้เก่า จังหวัดกาฬสินธุ์"** โดยนำแนวคิดและจุดเด่นของการวิเคราะห์ทรัพย์สินเชิงลึก (เช่น โมเดล FastLEDChecker.com) มาประยุกต์ใช้ เพื่อสร้างระบบที่สามารถสืบค้น กรองข้อมูลเชิงลึก วิเคราะห์ความคุ้มค่าในการลงทุน คำนวณราคาประมูลที่เหมาะสม ประเมินมูลค่าสิ่งปลูกสร้างไม้เก่า และเป็นศูนย์กลางการเชื่อมโยงผู้ซื้อ ผู้ขาย และผู้รับเหมาในพื้นที่จังหวัดกาฬสินธุ์ ซึ่งจะช่วยยกระดับการเข้าถึงข้อมูลอสังหาริมทรัพย์และส่งเสริมเศรษฐกิจหมุนเวียน (Circular Economy) ในระดับท้องถิ่นได้อย่างมีประสิทธิภาพ

## 1.2 วัตถุประสงค์ของโครงการ

1. เพื่อออกแบบและพัฒนาเว็บไซต์และแอปพลิเคชันสำหรับรวบรวม ค้นหา และแสดงผลข้อมูลอสังหาริมทรัพย์และทรัพย์บังคับคดีในเขตพื้นที่จังหวัดกาฬสินธุ์อย่างเป็นระบบ
2. เพื่อพัฒนาระบบตลาดออนไลน์ (Marketplace) เฉพาะกลุ่ม สำหรับการประกาศซื้อขาย ประเมินมูลค่าเบื้องต้น และเชื่อมโยงบริการรื้อถอนสิ่งปลูกสร้างไม้เก่าและวัสดุไม้รีไซเคิล
3. เพื่อสร้างเครื่องมือวิเคราะห์ข้อมูลทางการเงินและการลงทุนอสังหาริมทรัพย์ เช่น การคำนวณเพดานราคาประมูลที่เหมาะสม (Maximum Bid Calculator), การคำนวณต้นทุนแฝง และการประเมินผลตอบแทนจากการลงทุน (ROI)
4. เพื่ออำนวยความสะดวกและสร้างเครือข่ายการเชื่อมโยงระหว่างผู้ซื้อ ผู้ขาย นักลงทุน ประชาชนทั่วไป และผู้ให้บริการรื้อถอนบ้านไม้ในพื้นที่จังหวัดกาฬสินธุ์

## 1.3 ขอบเขตของโครงการ

### 1.3.1 ขอบเขตด้านพื้นที่และข้อมูล (Data Scope)
* **พื้นที่ดำเนินงาน:** ครอบคลุมข้อมูลอสังหาริมทรัพย์ ทรัพย์บังคับคดี และสิ่งปลูกสร้างไม้เก่า เฉพาะในเขตพื้นที่ **จังหวัดกาฬสินธุ์** (ทั้ง 18 อำเภอ)
* **การจัดการข้อมูลทรัพย์บังคับคดี:** นำเข้าข้อมูลผ่านระบบหลังบ้าน (Data Import) หรือกระบวนการจัดเก็บข้อมูลอัตโนมัติ (Web Scraping / Data Pipeline) จากแหล่งข้อมูลเปิดที่เกี่ยวข้อง
* **การจำแนกประเภทสิ่งปลูกสร้างไม้เก่า:** จัดหมวดหมู่ตามชนิดของไม้ (เช่น ไม้สัก, ไม้ประดู่, ไม้เต็ง, ไม้แดง), สภาพโครงสร้างอาคาร, และประเภทสิ่งปลูกสร้าง (เช่น บ้านเรือนไทย, บ้านไม้ครึ่งปูน, ยุ้งข้าวไม้เก่า)

### 1.3.2 ขอบเขตด้านผู้ใช้งาน (User Scope)
แบ่งผู้ใช้งานออกเป็น 4 กลุ่มหลัก ได้แก่
1. **ผู้ใช้งานทั่วไป (Guest / General User):** 
   * สามารถค้นหาและดูรายละเอียดเบื้องต้นของอสังหาริมทรัพย์และสิ่งปลูกสร้างไม้เก่า
   * สามารถใช้งานเครื่องมือคำนวณราคาประมูลและประมาณการต้นทุนขั้นพื้นฐาน
2. **สมาชิกระดับพรีเมียม / นักลงทุน (Premium User / Investor):** 
   * สามารถเข้าถึงฟังก์ชันวิเคราะห์เชิงลึก (Deep Analytics Dashboard)
   * สามารถคำนวณเพดานราคาประมูลสูงสุด (Maximum Bid Calculator)
   * ตรวจสอบรายละเอียดภาระผูกพัน (เช่น ภาระจำนองติดไป, สถานะผู้อยู่อาศัย) และบันทึกทรัพย์สินที่สนใจเพื่อรับการแจ้งเตือน
3. **ผู้ขาย / ผู้รับเหมา (Seller / Vendor / Contractor):** 
   * สามารถลงประกาศขายอสังหาริมทรัพย์ สิ่งปลูกสร้างไม้เก่า หรือวัสดุไม้
   * นำเสนอคำขอประเมินราคาและรับงานบริการรื้อถอนสิ่งปลูกสร้างในพื้นที่
4. **ผู้ดูแลระบบ (Admin):** 
   * จัดการและอนุมัติรายการประกาศ (Moderation)
   * จัดการข้อมูลผู้ใช้งาน ระบบสมาชิก และดูแลรักษาความปลอดภัยของฐานข้อมูลระบบ

### 1.3.3 ขอบเขตด้านระบบและฟังก์ชันการทำงาน (System & Functional Scope)
* **ระบบค้นหาและกรองข้อมูลขั้นสูง (Smart Search & Filter):** รองรับการกรองตามรายอำเภอ ประเภททรัพย์สิน ช่วงราคา ชนิดไม้ และสถานะทางกฎหมาย
* **ระบบประเมินมูลค่าสิ่งปลูกสร้างไม้เก่า (Wood Valuation Engine):** คำนวณและประเมินมูลค่าไม้เก่าเบื้องต้นจากขนาด สภาพ และชนิดไม้
* **ระบบเครื่องมือคำนวณทางการเงิน (Interactive Financial Calculators):** ระบบคำนวณต้นทุนแฝง (ค่าโอน, ค่าปรับ, ค่าปรับปรุง, ค่ารื้อถอน) และเพดานราคาประมูลสูงสุด
* **ระบบแผนที่ปฏิสัมพันธ์ (Interactive Map Integration):** แสดงตำแหน่งทรัพย์สินและสิ่งปลูกสร้างไม้เก่าบนระบบแผนที่ดิจิทัล

## 1.4 ผลที่คาดว่าจะได้รับ

1. ประชาชนและนักลงทุนมีแพลตฟอร์มศูนย์รวมข้อมูลอสังหาริมทรัพย์และทรัพย์บังคับคดีในจังหวัดกาฬสินธุ์ ที่เข้าถึงง่าย ช่วยลดความเสี่ยงและความซับซ้อนในการตัดสินใจประมูลทรัพย์สิน
2. เกิดศูนย์กลางตลาดดิจิทัล (Digital Marketplace) สำหรับซื้อขายและประเมินมูลค่าสิ่งปลูกสร้างไม้เก่า ช่วยเพิ่มมูลค่าทางเศรษฐกิจให้กับทรัพย์สินท้องถิ่น และส่งเสริมแนวคิดเศรษฐกิจหมุนเวียน (Circular Economy)
3. ผู้ใช้งานได้รับประโยชน์จากเครื่องมือประมวลผลทางการเงินที่แม่นยำ ช่วยลดระยะเวลาและป้องกันข้อผิดพลาดในการคำนวณต้นทุนแฝงและเพดานราคาประมูล
4. ช่วยกระตุ้นและส่งเสริมเศรษฐกิจระดับท้องถิ่นในจังหวัดกาฬสินธุ์ ผ่านการเชื่อมโยงระบบนิเวศธุรกิจ (Ecosystem) ระหว่างผู้ซื้อ ผู้ขาย นักลงทุน และผู้รับเหมารื้อถอนในพื้นที่

## 1.5 เครื่องมือและเทคโนโลยีที่ใช้ในการดำเนินงาน

### 1.5.1 ด้านฮาร์ดแวร์ (Hardware)
* เครื่องคอมพิวเตอร์ประมวลผลสูง สำหรับการเขียนโปรแกรม ประมวลผลข้อมูล และพัฒนาระบบ (Development Workstation)
* ระบบเครื่องแม่ข่ายคลาวด์ (Cloud Server / Virtual Private Server) สำหรับการจำลอง สภาพแวดล้อมระบบ และการโฮสต์เว็บไซต์ (Web Hosting)

### 1.5.2 ด้านซอฟต์แวร์และเทคโนโลยี (Software & Technology Stack)
* **การออกแบบส่วนต่อประสานผู้ใช้ (UI/UX Design):** 
  * Figma หรือ Adobe XD สำหรับออกแบบ Wireframe, UI Components และ Prototype
* **เทคโนโลยีส่วนหน้า (Frontend Development):** 
  * HTML5, CSS3, JavaScript (TypeScript)
  * React.js หรือ Next.js ร่วมกับ Tailwind CSS สำหรับสร้าง Responsive Web & Mobile Application Interface
* **เทคโนโลยีส่วนหลัง (Backend Development & Data Pipeline):** 
  * Node.js (Express.js) หรือ Python (FastAPI / Django) สำหรับพัฒนา RESTful APIs
  * Python Libraries (BeautifulSoup, Selenium, Pandas) สำหรับกระบวนการจัดเก็บและประมวลผลข้อมูล (Web Scraping & Data Cleansing)
* **ระบบจัดการฐานข้อมูล (Database Management Systems):** 
  * PostgreSQL หรือ MySQL สำหรับจัดเก็บข้อมูลโครงสร้างเชิงสัมพันธ์ (Relational Data)
  * Redis หรือ MongoDB สำหรับ Caching และจัดเก็บข้อมูลแบบ Unstructured / JSON
* **เครื่องมือควบคุมเวอร์ชันและทดสอบระบบ (Version Control & Deployment Tools):** 
  * Git และ GitHub/GitLab สำหรับการบริหารจัดการซอร์สโค้ด
  * Docker สำหรับทำ Containerization และรองรับการนำระบบขึ้นสู่สภาวะใช้งานจริง (Deployment)
