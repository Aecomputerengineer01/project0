# 1.3 ขอบเขตของโครงการ

การดำเนินโครงการพัฒนาเว็บไซต์และแอปพลิเคชันตลาดอสังหาริมทรัพย์ ทรัพย์บังคับคดี และสิ่งปลูกสร้างไม้เก่า จังหวัดกาฬสินธุ์ กำหนดขอบเขตการทำงานออกเป็น 4 ด้านหลัก ได้แก่ ขอบเขตด้านประชากรและข้อมูล ขอบเขตด้านผู้ใช้งาน ขอบเขตด้านฟังก์ชันการทำงาน และขอบเขตด้านข้อจำกัดทางเทคโนโลยี ดังรายละเอียดต่อไปนี้

---

### 1.3.1 ขอบเขตด้านประชากร ข้อมูล และพื้นที่ (Data & Geographic Scope)

1. **ขอบเขตพื้นที่ดำเนินงาน (Geographic Scope):**
   * ครอบคลุมอสังหาริมทรัพย์ ทรัพย์บังคับคดี และสิ่งปลูกสร้างไม้เก่า เฉพาะในเขตพื้นที่ **จังหวัดกาฬสินธุ์** ทั้ง 18 อำเภอ ได้แก่ อำเภอเมืองกาฬสินธุ์, กมลาไสย, ยางตลาด, ฆ้องชัย, ร้องเอ็ด, สมเด็จ, กุฉินารายณ์, ห้วยผึ้ง, สหัสขันธ์, คำม่วง, ท่าคันโท, หนองกุงศรี, ห้วยเม็ก, นาคู, เขาวง, นามน, ดอนจาน และสามชัย

2. **ขอบเขตประเภทข้อมูล (Data Parameter Scope):**
   * **ข้อมูลอสังหาริมทรัพย์และทรัพย์บังคับคดี:** เลขที่แปลง/โฉนด, ตำแหน่งพิกัดละติจูด-ลองจิจูด, ราคาประเมินกรมธนารักษ์, ราคาเริ่มต้นการประมูล, ประเภททรัพย์ (บ้านเดี่ยว, ที่ดินเปล่า, ทาวน์เฮาส์, อาคารพาณิชย์), สถานะทางกฎหมาย (ภาระจำนองติดไป, ปัญหาสิทธิการเช่า/ผู้อาศัย)
   * **ข้อมูลสิ่งปลูกสร้างไม้เก่า:** ชนิดของไม้ (ไม้สัก, ไม้ประดู่, ไม้เต็ง, ไม้แดง, ไม้ตะเคียน ฯลฯ), ขนาดโครงสร้างกว้างxยาวxสูง, จำนวนเสาเรือน, สภาพความสมบูรณ์ของเนื้อไม้ (เปอร์เซ็นต์), ประเภทสิ่งปลูกสร้าง (เรือนไทยโบราณ, บ้านไม้ครึ่งปูน, ยุ้งข้าว, วัสดุแผ่นไม้แปรรูป)

3. **ขอบเขตการจัดเก็บข้อมูล (Data Acquisition Pipeline):**
   * ข้อมูลอสังหาริมทรัพย์และทรัพย์บังคับคดีจะจัดเก็บผ่านกระบวนการดึงข้อมูลอัตโนมัติ (Web Scraping & Data Pipeline) จากแหล่งข้อมูลเปิดทางราชการ และรองรับการนำเข้าข้อมูล (Data Import/CSV/JSON) โดยผู้ดูแลระบบ

---

### 1.3.2 ขอบเขตด้านผู้ใช้งานและสิทธิ์การเข้าถึง (User Roles & Access Control Scope)

การออกแบบระบบกำหนดสิทธิ์เข้าถึงใช้งานตามบทบาทผู้ใช้งาน 4 กลุ่มหลัก ได้แก่

| กลุ่มผู้ใช้งาน (User Role) | ขอบเขตสิทธิ์การใช้งานและฟังก์ชันที่รองรับ |
| :--- | :--- |
| **1. ผู้ใช้งานทั่วไป (Guest / General User)** | - ค้นหาและเรียกดูรายการทรัพย์สิน และสิ่งปลูกสร้างไม้เก่า<br>- ดูข้อมูลตำแหน่งบนแผนที่ปฏิสัมพันธ์ (Map View)<br>- ใช้งานเครื่องมือคำนวณราคาประมูลเบื้องต้น (Basic Maximum Bid Calculator)<br>- สมัครสมาชิกและลงชื่อเข้าใช้งานระบบ |
| **2. สมาชิกระดับพรีเมียม / นักลงทุน (Premium User / Investor)** | - เข้าถึงฟังก์ชันวิเคราะห์เชิงลึก (Deep Investment Analytics)<br>- ตรวจสอบรายงานประเมินภาระติดไปและรายละเอียดต้นทุนแฝงเชิงลึก<br>- ใช้งานเครื่องมือคำนวณเพดานราคาประมูลแบบปรับแต่งพารามิเตอร์ขั้นสูง<br>- บันทึกรายการทรัพย์สินโปรด (Watchlist) และตั้งค่าระบบแจ้งเตือนทรัพย์ใหม่ (Alert System) |
| **3. ผู้ขาย / ผู้รับเหมา (Seller / Vendor / Contractor)** | - ลงประกาศขายอสังหาริมทรัพย์ สิ่งปลูกสร้างไม้เก่า และวัสดุไม้<br>- เสนอราคาประเมินและยื่นความจำนงรับงานบริการรื้อถอน/ขนย้าย<br>- จัดการข้อมูลประกาศ และติดต่อสื่อสารกับผู้ซื้อผ่านระบบส่งข้อความ |
| **4. ผู้ดูแลระบบ (System Administrator)** | - ตรวจสอบและอนุมัติประกาศซื้อขาย (Content Moderation)<br>- จัดการข้อมูลสมาชิกและสิทธิ์การเข้าถึงระบบ<br>- บริหารจัดการฐานข้อมูล สถิติการใช้งาน และความปลอดภัยของระบบ |

### 1.3.3 ขอบเขตด้านสถาปัตยกรรมระบบและฟังก์ชันการทำงาน (System Architecture & Functional Scope)

ระบบประกอบด้วย โมดูลฟังก์ชันหลัก 5 ระบบ ได้แก่

```
+---------------------------------------------------------------------------------+
|                       ระบบตลาดอสังหาริมทรัพย์และสิ่งปลูกสร้างไม้เก่า                   |
+---------------------------------------------------------------------------------+
        |                    |                    |                    |
+---------------+    +---------------+    +---------------+    +---------------+
| 1. Smart Filter|    |2. Marketplace |    | 3. Analytics  |    | 4. User/Admin |
|   & Map View  |    |  & Valuation  |    |  Calculator   |    |   Management  |
+---------------+    +---------------+    +---------------+    +---------------+
```

1. **ระบบค้นหาและกรองข้อมูลเชิงพื้นที่ (Smart Search & Map Filter Module):**
   * การค้นหาด้วยคำสำคัญ (Keyword Search) และการกรองหลายมิติ (Multi-criteria Filter)
   * การแสดงผลตำแหน่งทรัพย์สินบนแผนที่ดิจิทัล (Google Maps API / OpenStreetMap) พร้อมระบบหมุดระบุประเภททรัพย์สิน (Custom Map Markers)

2. **ระบบตลาดกลางและการประเมินมูลค่าสิ่งปลูกสร้างไม้เก่า (Marketplace & Valuation Module):**
   * ระบบลงประกาศซื้อขายสิ่งปลูกสร้างไม้เก่าพร้อมการอัปโหลดรูปภาพและเอกสารสิทธิ์
   * ระบบคำนวณและประเมินมูลค่าไม้เก่าเบื้องต้นตามอัลกอริทึมปริมาตรไม้และประเภทไม้
   * ระบบจับคู่ผู้รับเหมารื้อถอน (Contractor Matching System)

3. **ระบบเครื่องมือคำนวณและวิเคราะห์การลงทุน (Interactive Investment Analytics Module):**
   * ระบบคำนวณเพดานราคาประมูลสูงสุด (Maximum Bid Engine)
   * ระบบคำนวณต้นทุนแฝงการรื้อถอน ขนย้าย และการฟ้องร้องขับไล่
   * ระบบประมาณการอัตราผลตอบแทนจากการลงทุน (ROI & Rental Yield Estimator)

4. **ระบบจัดการสิทธิ์และบัญชีผู้ใช้งาน (User & Authentication Module):**
   * ระบบยืนยันตัวตน (Authentication & Authorization) ผ่าน JWT / OAuth 2.0
   * ระบบสมัครสมาชิกและการจัดการสิทธิ์ตามบทบาท (Role-Based Access Control: RBAC)

5. **ระบบบริหารจัดการหลังบ้าน (Admin Control Panel Module):**
   * Dashboard สรุปสถิติทรัพย์สิน จำนวนสมาชิก และปริมาณธุรกรรมในระบบ
   * ระบบอนุมัติและจัดการประกาศ (Listing Moderation & Management)

---

### 1.3.4 ขอบเขตด้านข้อจำกัดของโครงการ (Project Limitations)

1. **ข้อจำกัดด้านความสดใหม่ของข้อมูล (Data Timeliness):** ความถี่ในการอัปเดตข้อมูลทรัพย์ขายทอดตลาดของกรมบังคับคดีขึ้นอยู่กับรอบการจัดทำ Data Pipeline และกฎเกณฑ์การเผยแพร่ของหน่วยงานต้นทาง
2. **ข้อจำกัดของการประเมินราคาไม้เก่า:** การประเมินมูลค่าไม้เก่าในระบบเป็นการประเมินเบื้องต้นตามอัลกอริทึมทางคณิตศาสตร์ (Algorithmic Estimation) ไม่สามารถทดแทนการตรวจสอบสภาพเนื้อไม้จริง ณ สถานที่จริงโดยผู้เชี่ยวชาญได้ 100%
3. **ข้อจำกัดทางกฎหมาย:** ระบบเป็นสื่อกลางในการแสดงข้อมูลและเชื่อมโยงการซื้อขาย การตัดสินใจประมูลทรัพย์และทำนิติกรรมสัญญาขึ้นอยู่กับดุลยพินิจของคู่สัญญา
